# Approved partial-preview scope

The owner's in-chat design approval requests an automatic one-sentence overview
from any readable fetched content, replacing the proposed Generate button.
This is a bounded extension of acquisition failure, metadata generation, the USD
ledger and the queue. Canonical execution/acceptance state is progress.md.

Acceptance: partial text stays separate from complete source; a successful preview
stays labeled incomplete and Needs action, without research/assessment/score.
Retain existing text-only media policy. Use the existing provider, admission and
cost rules with explicit Submit/Retry disclosure and consent, one durable attempt,
owner/lease/account/expiry guards and late billing reconciliation. Old clients/jobs
remain unconsented; no extra click, silent paid retry, source refetch or backfill.

Trade-off: preserve at most 6,000 fragment characters in memory and only store the
sentence; a crash before generation requires a later explicit source Retry rather
than retained incomplete-source storage. Known or uncertain preview attempts are
not automatically resent. Migration 000021 precedes matching backend/frontend.

Verification: synthetic adapter/provider/service/API/UI tests, disposable SQL
ownership/budget/deletion/recovery and concurrent admission gates, red/green and
deliberate-break evidence, required Python/frontend checks and English editable
workflow. No paid or hosted action. Unrelated workspace work stays separate.
