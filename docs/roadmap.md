# Linksifty MVP roadmap

1. **Foundation:** application shells, local commands, test/type/lint gates, configuration, and architecture diagram.
2. **Identity and isolation:** Supabase authentication, RLS, pending/approved role flow, admin account approval, and trial allowance.
3. **Submission:** link normalization, five-link batch limit, duplicate detection, item lifecycle, and manual-content fallback.
4. **Assessment:** article and X adapters, structured assessment, pure scoring, verdict thresholds, referenced-link limit, and spend cap.
5. **Inbox:** responsive list, statuses, ordering, filtering, read state, and deletion.
6. **Item conversation:** source-bounded chat for a completed item.
7. **Production readiness:** CI, deploy configuration, observability, security review, and twenty-link verdict evaluation.

The dependency order is strict through milestone 5. Milestone 6 and referenced-link checking within milestone 4 are the agreed first cut-line candidates if the deadline is at risk.
